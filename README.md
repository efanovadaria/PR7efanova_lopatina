### Отладка консольного приложения «Фибоначчи»
### Использованные способы отладки
1. Точки останова (Breakpoints)
Использовались для остановки выполнения программы на определённой строке кода. Это позволило проверить текущее состояние приложения, значения переменных и найти место возникновения ошибки.

2. Пошаговое выполнение программы
Для анализа логики работы программы использовались инструменты пошагового выполнения кода.

3. Просмотр значений переменных
Помогает отслеживать изменения данных в процессе выполнения программы.

5. Запуск программы в режиме отладки
Программа запускалась в режиме Debug. Это позволило использовать все инструменты отладки и анализировать выполнение программы в реальном времени.

### Отладка консольного приложения «Галактики»
### Использованные способы отладки
1. Запуск программы в режиме отладки (Start Debugging)
Программа запускалась для отслеживания выполнения кода и поиска ошибок.

3. Использование точек останова (Breakpoints)
Точки останова устанавливались для приостановки выполнения программы на определённых строках кода и анализа состояния приложения.

4. Пошаговое выполнение программы
Применялись команды:
F11 — Step Into — вход внутрь метода;
F10 — Step Over — выполнение строки без входа в методы;
F5 — Continue — продолжение выполнения программы.

5. Просмотр значений переменных (Hover / Data Inspection)
При наведении курсора на переменные отображались их текущие значения, что помогало находить ошибки в данных.

6. Отладка с помощью окна Exception Helper
Visual Studio автоматически показывала место возникновения исключения и информацию об ошибке.

7. Hot Reload / Edit and Continue
Во время отладки код изменялся без полной остановки приложения, что позволяло быстро исправлять ошибки и повторно запускать программу.

8. Проверка выполнения ветвей кода
С помощью пошаговой отладки анализировалось прохождение программы через оператор switch, что позволило обнаружить опечатку в условии case 'I'.

9. Анализ типов объектов и свойств
Проверялись типы данных объектов (object и GType) и значения свойств (MyGType) для поиска логической ошибки в программе.

10. Перезапуск приложения во время отладки (Restart Debugging)
Использовалась команда Ctrl + Shift + F5 для повторного запуска программы после внесения исправлений.

### Отладка консольного приложения «Буквы»
### Использованные способы отладки
1. Запуск приложения в режиме отладки
Позволяет запускать программу под управлением отладчика.

2. Остановка отладки
Использовалась для завершения сеанса отладки.

3. Точки останова (Breakpoints)
Использовались для приостановки выполнения программы в нужной строке кода.

4. Пошаговое выполнение программы
F10 — Step Over — Выполнение строки без входа внутрь метода.
F11 — Step Into — Переход внутрь вызываемого метода.
Shift + F11 — Step Out — Выход из текущего метода.

5. Просмотр значений переменных
Наведение курсора на переменные (Data Tips / подсказки данных).
Проверялись значения:
-letters
-name
-элементы массива.

6. Инспектирование массивов
Раскрытие массива letters в подсказке данных. Просмотр значений элементов массива во время выполнения программы.

7. Использование команды Run to Click
Быстрый переход к определённой строке кода без установки постоянной точки останова.

8. Перезапуск приложения во время отладки
Использовался для быстрого повторного запуска программы.

9. Окно Autos
Просмотр автоматически определённых переменных, используемых в текущей строке кода.

10. Окно Locals
Просмотр локальных переменных текущего метода.

11. Окно Watch
Добавление переменной name в наблюдение. Отслеживание изменения значения переменной при каждой итерации цикла.

12. Проверка стека вызовов (Call Stack)
Анализ последовательности вызовов методов

13. Навигация по стеку вызовов
Переход к исходному коду методов через окно Call Stack.

14. Контроль выполнения цикла
Пошаговое выполнение цикла for.
Анализ изменения значений переменных на каждой итерации.

Вывод: В ходе работы были изучены основные возможности отладки в Microsoft Visual Studio. Были освоены запуск программы в режиме отладки, установка точек останова, пошаговое выполнение кода, просмотр значений переменных, использование окон Autos, Locals, Watch и Call Stack. С помощью инструментов отладки были найдены и исправлены ошибки в программе, а также добавлены XML-комментарии для документирования кода. Полученные навыки позволяют эффективно анализировать выполнение программы и находить ошибки в коде.
